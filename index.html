Frequently Asked Questions

How does lossless metadata excision work?

In JPEG format, metadata is stored in separate APP1 (0xFFE1) and APP2 chunks before the compressed image scan data. Our tool reads the binary file structure, cuts out the metadata chunks, and re-stitches the image stream cleanly without decoding or re-encoding the compressed pixels.

Can an attacker recover stripped GPS tags?

No. Once the EXIF and GPS byte chunks are excised from the file structure, the metadata bytes cease to exist in the exported file.

Does this support PNG files as well?

Yes. PNG metadata chunks (such as tEXt, zTXt, and eXIf) are similarly identified and excised.

Does this tool work completely offline?

Yes. You can disconnect from the internet and purify as many high-resolution photos as needed.
